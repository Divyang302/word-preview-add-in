📄 Install the Word Add-in

Option A: Automatic (recommended)

  1. Download the package (.zip) and extract it to a folder (e.g. C:\WordAddinInstall)
  2. Close Word, then double-click Install.bat
  3. Click Yes when Windows asks for permission. This trusts the certificate
  4. The installer starts. Click Install, then open Word

Option B: Manual

  1. Download the certificate
  2. Double-click it → Install Certificate → Local Machine. Install it into both Trusted Publishers and Trusted Root Certification Authorities
  3. Close Word, then install the add-in in one of these ways:
    • Open the .vsto link in Microsoft Edge, or
    • Download the package (.zip), extract it, and double-click WordPreviewAddIn.vsto
    If the add-in doesn't install, run setup.exe instead. It also installs any missing prerequisites.
  4. Open Word. The add-in appears in the ribbon

Updating or reinstalling

  • Close Word and uninstall MorasalaTec Add In in Settings → Apps first
  • Then use either option above
