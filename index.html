📄 Install the Word Add-in

⚠️ Before you install Go to Start menu → Add or remove programs and search for MorasalaTec Add In. If it is installed, uninstall it first, then follow the steps below. Why: an older version can conflict with the new one and cause the install to fail.

Automatic install

  1. Download and extract the package. Download the package (.zip), then extract it to a simple folder such as C:\WordAddinInstall. Why: the installer needs all the files together in one folder, and a short path without spaces avoids errors.
  2. Close Word, then double-click Install.bat. Why: Word must be closed so the add-in can register with it correctly.
  3. Click Yes when Windows asks for administrator permission. This adds the included MorasalaTec certificate to Windows' trusted certificate stores. Why: this add-in is signed with its own certificate, not one from a commercial authority. Windows only installs add-ins whose signer it trusts, so this one-time step tells Windows to trust it. The certificate is used only for this add-in, and you can remove it later from the Windows certificate manager if you wish.
  4. Click Install, then open Word. The installer starts automatically after the certificate is added. Why: this registers the add-in with Word. It will appear in the ribbon the next time Word opens.
